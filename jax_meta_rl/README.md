# JAX Meta-RL Project

This project is a collection of Meta-Reinforcement Learning algorithms implemented in JAX.

## Environment Setup

### 1. Install PyTorch
First, install PyTorch according to your system's configuration (CPU or GPU). Visit the [official PyTorch website](https://pytorch.org/get-started/locally/) to find the correct installation command for your setup.

Example (CPU-only):
```bash
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
```

### 2. Install Project Dependencies
Once PyTorch is installed, you can install the rest of the project dependencies:
```bash
pip install -r requirements.txt
```
This project is tested with Python 3.10 and 3.11.
